# ตารางสรุปผลการเปรียบเทียบ (REST vs GraphQL)
## 67160028 ณัฐวุฒิ รู้การนา

ตารางสรุปเปรียบเทียบประสิทธิภาพในการดึงข้อมูลระหว่าง REST API และ GraphQL ตามขั้นตอนปฏิบัติการสัปดาห์ที่ 2

| หัวข้อเปรียบเทียบ | REST (`/api/v1/students/:id`) | GraphQL |
| :--- | :--- | :--- |
| **จำนวนคำขอที่ใช้เพื่อดูชื่อและรายวิชาของนักศึกษา 1 คน** | **มากกว่า 1 คำขอ**<br>(ต้องดึงข้อมูลนักศึกษาก่อน จากนั้นนำ `courseIds` ไปยิงคำขอเพื่อดึงชื่อวิชาอีกครั้ง หรือถ้าใช้ `/students/:id/full` จะได้ฟิลด์ที่ไม่จำเป็นติดมาด้วย) | **1 คำขอ**<br>(ได้เฉพาะฟิลด์ `name` และ `courses.courseName` ตามที่เลือก) |
| **จำนวนคำขอที่ใช้เพื่อดูชื่อและรายวิชาของนักศึกษาทุกคน** | **มากกว่า 1 คำขอ**<br>(ต้องยิงดึงนักศึกษาทั้งหมด และยิงตามจำนวนวิชา/คนเพิ่มเติม) | **1 คำขอ**<br>(ดึงข้อมูลซ้อนกันได้ใน query เดียว) |
| **ฟิลด์ที่ได้รับเกินความจำเป็น (over-fetching)** | **มี**<br>(ได้รับฟิลด์ทั้งหมดเช่น `id`, `major` แม้จะต้องการใช้แค่ `name`) | **ไม่มี**<br>(เลือกฟิลด์ที่เจาะจงได้ทั้งหมด) |
